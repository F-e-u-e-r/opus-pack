# Static discrimination — coverage-before-clearance (7/7; expected verdicts written before determination; doctrine-level, no behavioral probe)

| # | Control | Setup | Expected | Landed clause that carries it | Verdict |
|---|---|---|---|---|---|
| C1 | EXTRA | brief allows A/B; diff carries unexplained C | no full clearance; C not auto-fraud | "an extra path … never silently absorbed, and never auto-filed as misconduct" | HOLDS |
| C2 | MISSING-CLAIM | brief requests A/B; packet carries only A; consumed as all-reviewed | B = UNREVIEWED; clearance binds A only | "a required path never made available and never examined is UNREVIEWED, never clean" | HOLDS |
| C3 | UNCHANGED | brief allows A/B; only A changed | B's absence from the diff is not a failure | "unchanged material legitimately produces no diff to review" (verified, not assumed) | HOLDS |
| C4 | AUTHORIZED-DERIVED | brief authorizes generated artifact C | C not misjudged as unexplained extra | "an authorized producer's output" | HOLDS |
| C5 | DISCOVERED-DEPENDENCY | unauthorized C found necessary mid-work | escalate/re-scope; not silent accept, not auto-reject | "a discovered dependency to escalate and re-scope" | HOLDS |
| C6 | SUBSET | reviewer assigned A only | judges A only; PROCEED never inflates | "a reviewer assigned a subset judges that subset — its PROCEED never expands" | HOLDS |
| C7 | DIRECT-ACCESS | packet embeds no B diff; reviewer holds trusted frozen-copy access; verdict evidence shows B examined | NOT misjudged as coverage-missing | "trusted access to the frozen tree all qualify; availability is not prompt-embedding" + "COVERED scope (what the verdict's own evidence shows was examined)" | HOLDS |

C7 exists specifically to keep the rule from degrading into a prompt-attachment-equality requirement.
