# Coverage-before-clearance — design + landing record (candidate ⑬)

**Landed rule:** `delegation-and-review` §3, immediately after the packet-errors rule, as its declared pair — *claims before findings; coverage before clearances*. Spine: **a clean verdict is never evidence about material the reviewer did not receive or otherwise verify.**

## Trail

1. **Orientation (read-only, falsification-first).** The intake question was whether brief-vs-diff reconciliation was already covered. Four candidate coverages were read in full and each individually passes a constructed counterexample: the §2 owned-scope declaration (dispatch-side only), the completion-claim audit (dishonesty-bound, bound to an execution deliverable, claim-side), the packet-errors rule (finding-side only), and the settled-tree protocol (motion-bound). Counterexample: an honest reviewer PROCEEDs over a silently-truncated packet (a pagination cap dropped one requested file's diff) and the orchestrator reads the verdict as full-requested-scope clean — **false clearance, zero rule violations**.
2. **Adjudication: PARTIAL-GAP.** The locked invariant: **credited clearance scope ⊆ actually covered scope**, reconciled over three distinct concepts (REQUIRED scope / AVAILABLE material / COVERED scope), explanation-based — deliberately NOT path-set equality. Missing required material → UNREVIEWED (sole carve-out: the orchestrator's own independent verified-unchanged ground truth). Extra paths → authorized producer output, or a discovered dependency to escalate, or outside the clearance — never auto-fraud, never silent absorption. A subset reviewer's PROCEED never inflates. Trusted frozen-tree access satisfies availability (availability is not prompt-embedding). Truncation/pagination is a dispatch coverage defect, never reviewer fault. No machine-readable manifest.
3. **Design review (r1, dual-blind, mutually blind, isolated dirs, identity from tool banners):** gpt-5.6-luna (max) — PROCEED · gpt-5.6-sol (max) — PROCEED. **2/2, zero findings**; both reviewers answered all ten mandatory axes line-anchored and both explicitly confirmed correctness requires no new runtime path-set tooling. Verdicts in `verdicts/`.
4. **Landing.** The reviewed rule and Provenance blocks landed **byte-verbatim** (`FINAL-WORDING-RECONSTRUCTION.md`); declared landing adaptations: NONE.
