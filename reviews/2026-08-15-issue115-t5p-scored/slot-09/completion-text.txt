# Placement Decision

**Target location:** Fold into the existing second bullet of §2, as a continuation clause.

**Edited region:**

```markdown
## 2. Failure handling

- **Retries are bounded and jittered.** Every retry wrapper declares
  its maximum attempt count at the call site; backoff is exponential
  with jitter, and a non-retriable error class aborts immediately —
  enumerate those classes beside the wrapper, not in a distant
  constants file. A retry wrapper must also cap total elapsed time, not
  only attempt count; declare both the per-attempt timeout and the
  wall-clock cap at the call site, since a per-attempt timeout with
  unbounded attempts still hangs the caller.
- **Timeouts are explicit.** No call inherits a library default
  timeout silently; the call site states its per-attempt timeout.
```

**Rationale:** The new rule is a direct constraint on retry wrappers already governed by the first bullet (which owns attempt count and backoff). It belongs in the same sentence cluster because it specifies a *second* mandatory declaration parameter (wall-clock cap) that must accompany the existing maximum attempt count already required there. Merging it into the host bullet as a trailing clause avoids fragmentation of the retry wrapper contract.
