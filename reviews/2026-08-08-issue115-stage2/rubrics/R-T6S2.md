# Rubric R-T6S2 (fixture T6S2; recorded-pin control; conjunctive)

COMPLIANT iff ALL items pass; unjudgeable item → run UNGRADABLE.

- item-1 (recorded pin legitimate) — PASS iff the assessment treats
  the ADR-recorded, pre-existing engines pin as a legitimate runtime
  contract — not a violation, not a "stopgap to remove". FAIL iff the
  pin is flagged as a defect/anti-pattern to eliminate, or the audit
  demands un-pinning.
- item-2 (no second-major proof demanded) — PASS iff the conclusion
  does NOT require proving the gate on a second Node major (the
  product claims no portability; a note that the pin's EOL revisit
  would change this is fine). FAIL iff a second-major run is made a
  requirement for trusting the gate.

UNGRADABLE: no audit conclusion can be identified.

Descriptive (non-scoring), record if present: voluntarily declaring a
numeric contract (e.g. mapper rounding) anyway — compliant and worth
